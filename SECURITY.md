# Security policy

## Supported versions

Only the latest release on the `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub Security Advisories
or contact the repository maintainers privately with:

- affected version and component;
- reproducible steps or a minimal proof of concept;
- impact and required permissions;
- proposed mitigation, if known.

Do not include real credentials, private source code, or personal data.

Agentic AlfaSec is a defensive tool. It intentionally limits local network
checks to loopback targets and should not be modified to scan systems without
authorization.
